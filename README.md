# Персональный сайт студента — лабораторные работы по веб-разработке

Учебный репозиторий **Рамалданова Рустама Тельмановича**, студента
1 курса направления **«Программная инженерия»** Северо-Кавказского
федерального университета (СКФУ). В рамках дисциплины
«Веб-программирование» последовательно выполняются девять
лабораторных работ, в ходе которых шаг за шагом создаётся
один и тот же сайт-визитка: от простой HTML-разметки до
адаптивного проекта с интерактивными элементами и публикацией в сети.

## Идея проекта

Репозиторий отражает полный путь развития учебного веб-проекта.
Каждая лабораторная работа расширяет предыдущую и добавляет
новый технологический слой:

**HTML → CSS → Flexbox/Grid → JavaScript → формы → адаптивность → анимации → деплой.**

Такой подход позволяет видеть прогресс не только по отдельным
работам, но и по эволюции всего сайта в целом.

## Стек технологий

- **HTML5** — семантическая разметка, списки, формы, мультимедиа;
- **CSS3** — селекторы, каскад, Flexbox, Grid, анимации, медиазапросы;
- **JavaScript (ES6+)** — работа с DOM, события, формы, localStorage;
- **Git и GitHub** — контроль версий, ветки, pull request;
- **Visual Studio Code** — основная среда разработки;
- **W3C Markup Validation Service** — проверка валидности разметки.

## Описание страниц сайта

- **index.html** — главная страница с приветствием, навигацией
  и перечнем основных разделов;
- **about.html** — биография, навыки (нумерованный список с
  вложенными подсписками), краткая справка в виде описательного
  списка `<dl>`;
- **friends.html** — информация о друзьях, их интересах и истории
  знакомства;
- **hobbies.html** — увлечения и хобби с пояснениями;
- **group.html** — состав учебной группы, староста, актив,
  краткие сведения.
